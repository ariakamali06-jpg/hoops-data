# Hoops Data 🏀

فید داده‌ی اپلیکیشن **Hoops** — اخبار بسکتبال ایران، NBA و یورولیگ.

این مخزن **عمومی** است چون محتوایش از طریق CDN رایگان jsDelivr سرو می‌شود
و باید برای همه قابل دسترسی باشد.

## چرا این مخزن وجود دارد؟

اپلیکیشن اندروید **هرگز مستقیماً سایت‌ها را اسکرپ نمی‌کند.** به‌جای آن:

```
اسکرپر (روی سیستم توسعه)  →  data/news.json  →  GitHub  →  jsDelivr CDN  →  اپلیکیشن
```

این الگو مزایای زیادی دارد:

- **پایداری:** تغییر ساختار یک سایت خبری فقط اسکرپر را خراب می‌کند، نه اپ را.
- **سرعت:** اپ فقط یک فایل JSON کوچک دانلود می‌کند، نه چندین صفحه HTML سنگین.
- **هزینه‌ی صفر:** هاست، پهنای باند و کش همگی رایگان.
- **دسترسی از ایران:** jsDelivr در ایران پاسخگو و سریع است.

## منابع داده

| منبع | نوع | زبان | وضعیت |
|---|---|---|---|
| ورزش سه (search API) | API جست‌وجو با صفحه‌بندی | فارسی | ✅ اصلی |
| بی‌بی‌سی ورزشی | RSS | انگلیسی | ✅ |
| ایسنا | RSS عمومی + فیلتر کلیدواژه | فارسی | ⚠️ فقط در صورت وجود خبر بسکتبال |

> **نکته:** `irbf.ir` (فدراسیون بسکتبال) در زمان نگارش از هم داخل ایران و هم
> خارج، در دسترس نبود. اگر درست شد، به‌عنوان منبع نتایج و جدول رده‌بندی
> اضافه می‌شود.

## اجرا

```bash
python scraper.py
```

خروجی:

- `data/news.json` — نسخه خوانا با آرایه‌ی `sources` و گزارش سلامت منابع
- `data/news.min.json` — نسخه فشرده (همان داده، حجم کمتر) که اپ می‌خواند

### متغیر محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `HOOPS_PROXY` | `http://127.0.0.1:20811` | آدرس پراکسی برای منابعی که اتصال مستقیم جواب نمی‌دهد. خالی بگذارید تا فقط اتصال مستقیم استفاده شود. |

## لینک سرو در اپلیکیشن

```
https://cdn.jsdelivr.net/gh/ariakamali06-jpg/hoops-data@main/data/news.min.json
```

> jsDelivr فایل‌های commit شده روی `main` را کش می‌کند. تا حدود چند دقیقه
> بعد از push، نسخه تازه سرو می‌شود.
